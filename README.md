Spanish healthcare system is universal. This is on paper great however this project sought to analyze the geographies of Spain along with the framework 5 pillars of geographic acccessibility specifically looking at Access.  The intial data pulled on average amount of people on waitlists for each community in Spain. I initially hypothesized that larger communities would inherently have longer wait times and we did see this trend in some cases however these numbers were varying after adjusting for population. Considering that each autonomous community sets its own policies in Spain, I assumed that data analysis would not really help understand access, but moreso the effectiveness of healthcare policy and it's affect on access.
