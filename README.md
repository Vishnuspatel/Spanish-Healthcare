Spain's healthcare system provides universal coverage to its population, but universal coverage does not necessarily guarantee equal access. This project began as a small homework assignment for my Geography of Healthcare course, where I sought to examine healthcare accessibility across Spain using the Five A's of Geographic Accessibility framework, with a specific focus on Access. My initial analysis examined average healthcare waiting lists across Spain's autonomous communities. I initially hypothesized that larger and more populous regions would inherently experience longer waiting lists. While this trend appeared in some cases, the differences became less consistent after adjusting for population size. This opened up several new avenues for exploration. If population alone could not explain differences in accessibility, what other factors might be contributing? Given that Spain's autonomous communities have considerable authority over their own healthcare systems and policies, I began to consider whether differences in healthcare access were more closely associated with regional healthcare policies, resource allocation, and government priorities than population size alone. This led me to narrow the scope of the project and develop three primary research questions: 

  1. Do population size and socioeconomic factors relate to healthcare accessibility across Spain's autonomous communities?
  2. How do healthcare access and waiting times differ between two Spanish autonomous communities?
  3. Despite Spain's universal healthcare system, are differences in healthcare access associated with the political orientation and healthcare policies of regional governments?

This has developed into an ongoing research project investigating how a healthcare system can provide universal coverage while still experiencing regional disparities in access. More broadly, the project seeks to understand where these gaps exist, what factors might explain them, and where opportunities for improvement lie. As a note, data for this project has been collected from several sources, including Statista and Spain's Ministry of Health. The initial analysis was conducted using QGIS, with the project expanding to incorporate Python for web scraping and data extraction and Tableau for reporting. This remains an ongoing project, with several opportunities for further analysis and expansion, as outlined in the accompanying report.
